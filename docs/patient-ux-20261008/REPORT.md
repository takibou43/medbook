## ما تغير

- متابعة الدور تستخرج المستفيد من قائمة مواعيد الحساب الموثقة، وتعرض القرابة وموعد العودة الذي برمجه الطبيب. لا يُضاف اسم المريض إلى استجابة الحالة العامة، ولا يُستبدل فرد الأسرة بصاحب الحساب.
- أهداف اللمس المهمة 48 بكسل والأوقات 44 بكسل، مع تركيز مرئي وRTL. الإلغاء منفصل عن المتابعة ويحتاج نافذة تأكيد باسم المستفيد والطبيب والتاريخ والوقت، وحبس التركيز واستعادته.
- المواعيد القادمة أولًا، ثم الحجز والأسرة والعلاج. المنطقة والتنبيهات داخل إعدادات؛ ملف الطبيب أسفل مهام المريض. السابق يبدأ بعشرة مع عرض عشرة أخرى واستمرار فلتر الأسرة.
- الولاية والبلدية في بحث الطبيب والعيادة؛ تغيير الولاية يمسح البلدية؛ حالات فارغة ومسح الفلاتر. تحديد الموقع الحالي اختياري في قائمة الأطباء، والاختيار اليدوي متاح دائمًا.
- الأوقات مقسمة صباحًا ومساءً، مع أول وقت متاح وبقاء التاريخ والوقت والمستفيد عند الرجوع. لا تغيير لقواعد التوفر أو أسبقية الحجز أو إعادة التحقق عند التأكيد. بعد نجاح الحجز تختفي مرحلة التأكيد لمنع الإرسال المكرر من النموذج السابق.
- هاتف العيادة رابط اتصال، واتجاهات فقط من عنوان مسجل أو إحداثيات صالحة. متوسط التقييم مع العدد عند توفره؛ تفاصيل الطبيب تأتي من بياناته الفعلية.
- اسم MedBook وتاريخ عربي بتوقيت الجزائر موحدان. النص القديم للإشعار يُعرض بالاسم الموحد دون تعديل سجلاته. روابط الإشعارات تُضاف فقط للموعد الموجود في قائمة الحساب المصرح بها، ويظهر الموعد المقصود حتى لو كان ضمن السابق.

لا تغيير API أو مخطط قاعدة البيانات. تغييرا الخادم نصوص اسم المنصة فقط. الشعار والخلفيات والأصول وقواعد الصلاحيات والعائلة وخطط العلاج وخدمات الحجز دون تغيير. لم يوجد حقل موثوق يميز حسابات العرض في المخطط والبذور؛ لذلك لم تُستبعد الحسابات بتخمين الاسم ولم تُحذف بيانات.

## التحقق المحلي

- `frontend: npm run build` نجح؛ `npm test`: 25 ناجحًا، صفر فشل أو تخطي.
- `backend: npm ci --include=dev`, `npm run prisma:generate`, `npm run build` نجحت بتبعيات مستقلة وDATABASE_URL محلي وهمي، دون اتصال قاعدة أو db push.
- `npx vitest run tests/newDoctorAnnouncement.test.ts tests/newDoctorAreaNotifications.test.ts`: أربعة اختبارات ناجحة، دون إرسال Push.
- التشغيل الأول لـ CI نجح في 876 اختبار خادم وفشل توقع واحد لاسم «مادبوك» القديم؛ جرى تحديث التوقع إلى الاسم الموحد MedBook وإعادة الفحص الكامل قبل الدمج. اختبار الحمل الاختياري مستثنى صراحة في إعداد CI.
- `git diff --check` ناجح.
- البيئة المحلية Node 24؛ CI يستخدم Node 22 حسب إعداد المشروع ويختبر الخادم على PostgreSQL مؤقت منفصل، بما في ذلك الحجز والصلاحيات.

اختبار المتصفح بخادم fixture محلي: لا قاعدة بيانات أو رسائل أو دفع أو بيانات مرضى فعلية. سجل الكتابات في `isolated-write-evidence.json` يثبت payload ونتيجة الحالة في محاكاة الواجهة، ولا يثبت حفظًا في الخادم الإنتاجي.

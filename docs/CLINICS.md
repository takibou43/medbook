# إضافة العيادات

- صاحب العيادة ينشئ حسابًا وعيادة، ويمكنه إنشاء ملف طبيب بالحساب نفسه. الطبيب المستقل يستطيع إنشاء عيادته دون حساب ثانٍ.
- الطبيب ينضم إلى عيادة واحدة عبر دعوة مرتبطة ببريده، صالحة سبعة أيام ولمرة واحدة. يمكن إلغاء الدعوة.
- المساعد يُدعى للعمل مع طبيب محدد، وحسابه مشمول دون رسوم إضافية.
- سعر الطبيب المستقل 5000 دج شهريًا، وطبيب العيادة 4000 دج. أربعة أطباء = 16000 دج. صاحب العيادة الطبيب يُحسب مرة واحدة.
- الإدارة تراجع العيادة والأطباء وتفعّل اشتراك العيادة بعد تحديد عدد الأطباء المدفوع وتاريخ الانتهاء. لا توجد بوابة دفع آلي.
- العيادة النشطة لا تقبل أعضاء يتجاوزون السعة المدفوعة، حتى مع قبول دعوات متزامنة. قبل التفعيل يمكن إعداد الطاقم؛ التفعيل يتطلب سعة تغطيه.
- المرضى يبحثون عن الطبيب باسمه الكامل أو يتصفحون `/clinics` ويختارون طبيبًا للحجز. يظهر اسم العيادة مع الطبيب.
- ظهور الطبيب والحجز يتطلبان التوثيق وحسابًا نشطًا واشتراكًا صالحًا. أطباء العيادات التي لها صاحب يعتمدون على اشتراك العيادة؛ بيانات العيادات القديمة بلا صاحب تحتفظ بقواعد اشتراك الطبيب.
- تعديل اسم العيادة أو عنوانها أو موقعها يعيدها للمراجعة. المالك لا يستطيع تفعيل اشتراكه أو توثيق نفسه.

## الترحيل والتحقق

`prisma/migrations/20261001150000_clinic_ownership_and_billing/migration.sql` يضيف الحقول والعلاقات وجدول الدعوات دون حذف البيانات. اختُبر فوق المخطط السابق في PostgreSQL محلي معزول.

اختبارات العيادات تغطي الملكية، الحساب الواحد، إخفاء بيانات الدفع، الحجز وانتهاء الاشتراك، إلغاء الدعوة، قبول الدعوة مرة واحدة، سباق السعة وسباق انضمام الطبيب إلى عيادتين، وتعطيل المساعد.

نتيجة التحقق قبل دمج آخر main: 462 اختبارًا ناجحًا، واختبار الحمل الاختياري متخطى. نجح بناء الخادم والواجهتين، ومراجعة نموذج التسجيل ولوحة العيادة محليًا.

الإصدار الأول لا يوفر نقل الطبيب بين العيادات أو حذف عضويته من لوحة المالك؛ يُرفض الانضمام إلى عيادة ثانية. التفعيل والتجديد يدويان عبر الإدارة.

# أيقونات التخصصات

تستخدم واجهتا المريض والطبيب ملفات SVG محلية من Health Icons للأيقونات الأساسية: طب عام، أسنان، عيون، أطفال، أعصاب، قلب، أنف وأذن وحنجرة، نساء وتوليد، جراحة عامة، وأمراض جلدية. الأيقونات شفافة بلون طبي موحد. ملفات المريض مستقلة عن حزمة JavaScript وتُخدّم من استضافة MedBook نفسها؛ ونسخة الطبيب مضمّنة مباشرة لتبقى متجهية داخل الوصفة المطبوعة. لا تتصل الأيقونات بأي مصدر خارجي وقت التشغيل.

المصدر: [Health Icons](https://github.com/resolvetosavelives/healthicons)، ملفات الأيقونات المنشورة تحت CC0-1.0. نسخة الترخيص محفوظة في `healthicons-CC0-LICENSE.txt`.

تظل أسماء التخصصات نصًا ظاهرًا بجوار الرمز. التخصصات غير المطابقة لقائمة الرموز تستخدم سماعة الطبيب كرمز احتياطي، ولا يُخترع رمز تشريحي لتخصص غير ممثل.
